# 天童アリス - Tendou Aris

一个简洁优雅的蔚蓝档案角色主题网站，聚焦于天童アリス（Tendou Aris）。

## 角色简介

天童アリス是千年科学学园游戏开发部的核心成员，自称"AL-1S"。她拥有出色的游戏开发和编程能力，对游戏充满热情。

## 特点

- 🎨 简洁现代的设计风格
- 📱 完全响应式布局
- ✨ 优雅的卡片式界面
- 🎭 基于蔚蓝档案官方设定

## 本地运行

```bash
# 启动本地服务器
python3 serve.py

# 或使用 Python 内置服务器
python3 -m http.server 8000
```

然后访问 http://localhost:8000

## 技术栈

- 纯 HTML + CSS
- 无依赖，开箱即用
- 渐变背景和现代 UI 设计
